# KUC v0.3.9 corrective consumer-boundary release

KUC `v0.3.9` corrects the public consumer-artifact boundary discovered after
`v0.3.8` was published. A registry consumer can now create a full generic
artifact plan directly from KUC-issued opaque host projection leases.

## Public API

- `ConsumerArtifactStageBinding::from_host_projection_lease` consumes a
  KUC-issued `EguiTextCommandSurfaceHostProjectionLease` inside KUC.
- The consumer still cannot obtain a presentation token, host router, renderer
  callback, or `RawInput`; KUC retains lifecycle and evidence ownership.
- `UiTreeTextRoleTypography` now expresses a target logical line box with
  `font_size`, fractional `line_box_height`, and
  `baseline_from_line_box_top`. KUC measures the raster baseline for the same
  request and computes its private draw origin, so consumers do not encode
  font-engine-specific offsets.
- The target line box is carried into the raster request; line visibility and
  clipping use the same fractional line model, and physical canvas coordinates
  are quantized during drawing.

## Verification

- The foreign-consumer contract constructs the complete ten-stage selection
  plan from opaque scenario leases.
- Generic regressions cover fractional target line boxes, target-baseline to
  raster-origin conversion, and scale-2 physical quantization.
- Full workspace checks, lint, consumer contracts, and release validation run
  on the final release branch before publication.
- KLE will verify the exact registry crate on macOS, Linux, and Windows before
  KUC #40 is closed.
