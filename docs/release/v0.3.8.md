# KUC v0.3.8 unified consumer-contract release

KUC `v0.3.8` は #35、#37、#40、#43、#44 を一つの互換 release line で解決する
patch release である。consumer は独自の GUI runtime、DPI 補正、検索可視状態、renderer、
`RawInput` を持たずに、公開 KUC API と registry crate のみを利用する。

## 公開範囲

- framework-neutral raster host と四辺別 grid border の既存 public API を、KDV の
  registry-only consumer contract として検証する。
- generic consumer artifact plan を追加し、opaque leaf ID、generic interaction/effect class、
  host-projected token だけから、KUC-owned stage evidence と one-shot receipt を発行する。
- TextSurface gutter、Diagnostics、StatusBar、CommandChrome の physical raster と logical
  layout extent を scale 1 / 1.5 / 2 で一致させる。
- synchronized scenario session は search close、explicit reopen、options、replace mode、
  result position を KUC 内に保持する。
