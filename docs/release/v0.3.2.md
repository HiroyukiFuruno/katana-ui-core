# KUC v0.3.2 統合リリース

KUC `v0.3.2` は、このリリース対象として追跡されている KUC の全 open issue
（#13、#21、#22、#23、#24）を統合する。対象は generic gesture input、
issue-first release hygiene、retained full-editor root、strict coverage recovery、
RawInput pointer resolution である。

legacy opaque host-token decode の挙動は維持する。明示的な command-family identity
は additive versioned envelope だけで運び、未知 version と重複する明示 family は
fail closed とする。

公開は release commit の merge 後に GitHub Actions から行う。ローカルの
`cargo login` / `cargo publish` はリリース経路に含めない。
