# v0.5.0

KUC単独で利用できる公開rootの入力・表示・操作契約を改善するリリース。

公開enumへ`VisibleAtCaret`と`SelectionDialog`、ContextMenu resolverの型付き失敗variantを追加するため、次のminor版へ更新する。
exhaustive matchを使うhostは新しいvariantを扱う必要がある。従来のselection-only設定は維持する。

- 入力・IME確定後の最終selectionを通知し、左右矢印で方向に対応する選択端へ折り畳む。
- hard改行、CRLF、空行、末尾改行をlayout・gutter・AccessKitへ保持する。scroll用のextentと本文textureの描画寸法を分離し、空行による文字の伸張を防ぐ。RTL行の改行位置は論理行末のvisual edgeへ合わせる。
- caret位置でfloating toolbarを表示する明示設定を追加し、従来のselection-only設定を維持する。
- 非操作status labelをButtonやClickへ変換せずAccessKitへ公開する。
- 汎用file selection/search results dialogを同じ公開rootへ接続する。対象はopaque tokenで返し、検索処理やファイル読み書きはhostが所有する。
- UI selectionの方向・折返しaffinity・希望水平位置をopaque snapshotとして保存・復元する。確定していないpassやIME未確定状態を拒否する。
- 実frameからUnicode glyphのcrop・計測・caret・hit test・AccessKitを観測し、root/frame/artifact/receiptの対応を検証する。synthetic入力からnative OS originは認定しない。
- tab/groupのtyped proposalから対象・correlation・確定値を取得できるようにし、混在順序、操作可否、inline rename、group dragを扱う。
- 開いたタブメニューをlease同期後も元のopaque targetへ結合し、対象削除時は閉じる。検索ダイアログのEnterは現在の入力focusに限定し、履歴・取消等の操作を奪わない。
- backendのtexture上限に合わせた分割描画と、4096pxを超える長文末尾のglyph生成を修正する。
- 空行を含む本文の公開selection continuationと、検索queryの矢印反復中のfocusを修正する。
- ContextMenuの有効状態を表示直前に解決する汎用resolverを公開leaseへ追加する。閉時は照会せず、表示frameの描画・操作・AccessKit・記録へ最新値を揃え、失敗を型付きで返す。
- FFmpeg導入を表示依存から分離する既存CI修正を再検証し、Linux headless検証でXvfbのclient終了時resetが新規X11接続と競合する問題を是正する。実接続100回の回帰を追加する。
- 依存関係を互換範囲で更新し、既存の外部repo固有コード・コメントを整理する。

- 公開後のブランチ整理はlocalのみを既定とし、remote削除を明示オプションへ変更する。

`docs/context-menu-enabled-resolver.md` を参照。

- ファイル選択ダイアログのEnterを実際にフォーカス中の行・ボタンへ限定し、取消へのTab移動後に選択・移動が誤発行される問題を修正。

- タブの削除・ドラッグ不可への変更・祖先の折り畳みによって無効になったドラッグ状態を解除。タブ・グループの表示が同期で変わっても、実際のボタン解放でドラッグを終了する。

- 名前変更中に新しい設定で編集許可や入力欄が取り消された場合、保持していた編集画面を閉じ、古い変更要求による描画エラーを防ぐ。
- ダイアログ、タブ、メニュー、各表示部品のRGBA描画を共通の遅延タイル分割へ統一し、backendのtexture上限を守る。画素の保存、描画範囲の分割、既存操作を数値回帰で検証する。

- ダイアログを開くframeから背景のクリック・ドラッグ・入力focusを停止し、開いていたメニューにも親の無効状態を伝える。中断するtab dragはhostへ取消を通知し、ダイアログを閉じた後の通常操作へ復帰する。

- lease同期中のドラッグ取消が拒否された場合、本文・設定・版番号・host routerを旧状態に保ち、同じ版番号での再試行を可能にする。状態保持付き同期も同じ確定順序へ統一する。

- 継続中のタブドラッグは開始時のport/correlationへ終端を返し、有効なleaseを重ねて更新してもdropや取消を失わない。グループ名変更は要求のfalse→trueで再armし、同一要求の再表示を抑止する。

- softwrapの描画・上下移動用visual rowを保ち、自動gutter・可視論理行一覧・AX gutter targetは論理行ごとに一意化する。履歴・フィルター・オプションで検索条件を変更した後は旧結果の選択を解除し、Enterで新しい検索を要求する。
- 検索query・include・excludeのIME変換確定で、同じEnterから古い検索や結果選択を発行しない。変換確定後の通常Enterを受け付け、別の検索種別に残る未確定状態が現在の入力を妨げないようにする。
