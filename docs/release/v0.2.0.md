# KUC v0.2.0 generic 2D grid release

## Scope

KUC `v0.2.0` adds a format-neutral, two-dimensional virtualized grid for
large structured datasets. KDV `v0.4.0` consumes this public API to display
XLSX sheet artifacts while retaining all document semantics in KDV.

The release includes:

- fixed and variable row and column tracks;
- bounded visible, overscan, and frozen-cell materialization;
- frozen rows and columns;
- merged-cell spans and typed cell appearance;
- pointer hit-testing, keyboard navigation, and range selection;
- typed render-model validation and accessibility indexes.

KUC does not contain XLSX, formula, chart, KDV, or framework-specific
semantics.
