# KUC v0.3.0 grid-line visibility release

KUC `v0.3.0` preserves the format-neutral grid-line visibility flag from
`GenericGrid` through `UiGridProps`. Existing serialized models and consumers
continue to show grid lines by default.

This release closes the KDV `v0.4.0` spreadsheet adapter boundary without adding
spreadsheet or document semantics to KUC.
