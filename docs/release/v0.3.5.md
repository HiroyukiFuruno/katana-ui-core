# KUC v0.3.5 registry raster-host compatibility

KUC `v0.3.5` は KUC #35 / #37 と KDV #44 / #48 の registry compatibility
corrective release である。`v0.3.4` の公開済み artifact は変更せず、KDV が
registry-only で必要とする `raster-host` feature と per-side custom border API を
公開 crate `katana-ui-core` の additive API として提供する。

## 公開範囲

- 公開 package は `katana-ui-core` 一件だけとする。
- generic registry consumer は `katana_ui_core::raster_host` を使用し、Storybook の
  legacy root facade は既存 private visual 型群との互換性を維持する。
- Grid cell の per-side custom border は typed API として公開し、text clip と border
  描画を独立させる。
- ScrollArea 直下の Grid は描画・測定の両方で原子 node として扱い、viewport height
  優先、total height fallback を維持する。
- path/git dependency、consumer 固有 package、公開 crate の重複を追加しない。
