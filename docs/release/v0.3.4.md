# KUC v0.3.4 可変 viewport motion artifact

KUC `v0.3.4` は Issue #34 と OpenSpec change
`add-variable-viewport-motion-artifact` に対応し、resize を含む opaque full-motion
sequence を一つの検証可能な GIF/MP4 artifact へ出力する。

## 公開範囲

- 公開 package は `katana-ui-core` 一件だけとする。
- 既存の固定寸法 `MotionArtifactWriter::write_opaque` は変更しない。
- 可変 viewport 用 API、専用 manifest、source/decode/provenance/semantic evidence
  の自動契約を additive に追加する。
- consumer 固有の raster/compositor、KLE 固有型、path/git dependency は追加しない。
- 新 API は入力 PNG/provenance の保護のため、既存の staging/GIF/MP4/manifest
  出力先を `OccupiedOutputTarget` で拒否する。再出力時は未使用の出力先を指定する。
- 出力directoryをハンドルで固定し、公開ファイルはno-follow/create-newで書く。
  FFmpegのscratchはcaller出力treeから分離するため、`storybook-artifacts`限定で
  `cap-std` / `cap-fs-ext` / `same-file` / `tempfile` を追加する。
- 公開前・最終検証でdirectoryと各fileのidentity不一致を観測した場合は拒否する。
  namespaceはロックしないため、安定したpathが必要な間の外部変更防止はcallerが担う。
  非UTF-8出力pathは副作用前、scratch/executable pathはencode/manifest記録前に拒否する。
- PNGは1枚64 MiB、provenance JSONは1件1 MiBでbounded readし、改変・成長する巨大入力を拒否する。
  decoded working setの1 GiB上限と全frame/provenance/decodeの検証は維持する。
- AccessKitは同じcommit frameの実text-input nodeの値・Unicode scalars・boundsを検証し、
  内容のcanonical hashをmanifestへ結合する。公開APIテストで最終TreeUpdateとの一致も検証する。
