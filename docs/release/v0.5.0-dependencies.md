# v0.5.0 依存更新の判断

2026-10-26に直接依存、推移依存、lockfileと公開registryを照合した。

| 系列 | 採用版 | 判断 |
|---|---|---|
| minifb | 0.29.0 | 次系列へ更新。Waylandの旧0.29系依存を除去し、追加されたBack/Forwardボタンを既存入力テストで非対応として扱う |
| resvg / usvg | 0.49.0 | 次系列へ更新。KUCのSVG解析・render呼出しは移行可能で、既存の描画数値回帰を維持する |
| egui / eframe | 0.36.2 | 0.37.0を評価し、公開adapterの`AsId`削除・`Ui::id`変更を伴うため現行互換系列を維持する |
| serde_json | 1.0.154 | 最新互換版へ更新 |
| sha2 | 0.11.1 | 次系列へ更新し、既存digest契約を維持する |

minifbの更新でウィンドウ作成エラーのDisplayに原因文字列が含まれるようになったため、既存テストも原因を含む期待へ更新した。製品側へ独自の補修実装は追加していない。

全互換依存を再解決した結果、追加更新は0件だった。採用候補でworkspace全target・全featureの型検査、SVG描画11件、Storybookのウィンドウ入力262件が成功した。最終判定には、このlockfileを含む署名済みheadの全CI・完全release-checkを使用する。検証範囲や品質閾値は変更しない。

公式変更点: [minifb](https://github.com/emoon/rust_minifb/blob/master/CHANGELOG.md)、[resvg](https://github.com/linebender/resvg/blob/master/CHANGELOG.md)、[egui](https://github.com/emilk/egui/blob/master/CHANGELOG.md)、[eframe](https://github.com/emilk/egui/blob/master/crates/eframe/CHANGELOG.md)。公開crateの版とchecksumはCargo.lockへ固定している。
