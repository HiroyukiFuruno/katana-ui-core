# KUC v0.1.4 corrective release

## Reason

`v0.1.3` is already published and consumed by KDV. KDV v0.2.0 user acceptance found that multi-line range selection in Special Characters reused the endpoint horizontal slice for every selected visual line, causing middle lines such as `Japanese:` and `Emoji:` to be omitted from highlight and clipboard payload.

This corrective release fixes the KUC Canvas text selection contract so multi-line drag selection is interpreted as document text flow: first line from anchor to line end, intermediate lines complete, and final line from line start to focus.
