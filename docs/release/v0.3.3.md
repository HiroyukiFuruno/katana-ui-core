# KUC v0.3.3 単一 crate 公開

KUC `v0.3.3` は、`v0.3.2` で過剰に分割された公開 package を
`katana-ui-core` 1 crate へ統合する是正リリースである。責務分離は
`text_raster`、`svg_raster`、`egui` の公開 module と feature で維持し、
別名の crates.io package は作成しない。

既存の公開 Rust struct literal、legacy opaque token wire、versioned family envelope、
duplicate family の fail-closed 契約を維持する。KLE、KDV、KatanA の意味論や
label は持ち込まない。

公開は GitHub Actions の Trusted Publishing だけで行う。ローカルの
`cargo login` / `cargo publish` と長期 registry token は使用しない。

公開対象は `katana-ui-core` の version `0.3.3` だけであり、package dry-run もこの
crateだけを対象とする。workspace検証の対象は `katana-ui-core`、
`katana-ui-core-storybook`、`kuc-consumer-app` の3 packageである。
