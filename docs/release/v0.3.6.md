# KUC v0.3.6 canonical text-face selection

KUC `v0.3.6` は KUC #41 の patch release である。KDV v0.5.6 が KatanA と同じ
platform font candidate policy を registry-only で採用し、reference crop の文字幅と
glyph を再現するための additive public API を提供する。

## 公開範囲

- `PlatformTextFaceSelection::FirstCandidate` により、最初に有効化できた
  proportional/monospace candidate face を明示的に選択できる。
- `UiTreeCanvasRenderer`、`UiTreeStorybookHost`、`UiTreeSurfaceHost` は
  `with_text_raster_config` で typed config と face selection を受け取る。
- 既存の `new` は `PlatformTextFaceSelection::System` のままとし、generic family と
  emoji hash contract の既定挙動を変えない。
- KDV は crates.io の `katana-ui-core@0.3.6` を exact requirement で採用し、path/git
  override なしに KatanA candidate policy を指定する。
