# KUC v0.1.3 corrective release

## 理由

KDV v0.2.0 は、command / surface-control / task-control の host action を KUC 共通 builder API 経由で付与できる必要がある。

`v0.1.2` は remote git tag として既に存在し、KDV が immutable git dependency として消費している。一方で GitHub Release と crates.io は `v0.1.1` までで止まっている。既存 `v0.1.2` tag を付け替えると KDV の既存依存を壊すため、この API 追加は corrective release として `v0.1.3` を使う。

local release check は次で実行する。

```bash
KUC_RELEASE_ALLOW_VERSION_LINE_OVERRIDE=1 just VERSION=v0.1.3 release-check
```
