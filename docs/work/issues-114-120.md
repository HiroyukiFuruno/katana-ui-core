# v0.6.0: 公開タブ操作と検索履歴の受入条件

対象は #114、#115、#116、#117、#120、#121、#122。一つのDraft PRと一つのリリースで解決する。この文書は実装時の受入条件と検証対応を固定し、公開結果は各IssueとReleaseへ記録する。

## 完了条件

1. KUC単独の公開APIから7件の追加契約を利用でき、既存の既定操作を維持する。
2. 実full-rootの入力、typed event、host効果、focus/AccessKit、IME、stale/duplicate/one-shot、数値描画と実RGBAを自動検証する。
3. 直接・推移依存とlockfileを調査し、既存build/test/lint/AST/coverageの基準と対象を下げず全ゲートを通す。
4. Draft PRでCodex/自己レビュー、指摘修正とreply/resolve、P0/P1ゼロ、Ready、required checks、mergeを順に完了する。
5. 公式ActionsのGitHub Release/crates.io公開、registry版だけの契約検証、7 IssueのClose、ローカルbranch整理まで完了する。

検索algorithm、filesystem、本文store、アプリ固有の操作順位はhostに残す。他repositoryの採用・受入はKUCの完了条件へ加えない。

## 互換性

| 対象 | 維持する既定 | 追加契約 |
|---|---|---|
| 名前変更 | Enter確定とcancel | OnChange、空名、確定passの開始成立receipt |
| Group表示 | 色未設定の従来描画 | swatch候補から独立したmarker/background/member RGBA |
| Drop | Region | NearestGhostCenter、開始anchor/幅保持、末尾capability維持 |
| Proposal | 従来constructorはoriginなし | 操作経路を示すoptional typed origin |
| 検索query | Results navigation | mode別History、draft復元、履歴専用typed event |
| Global action | 未登録の既存rootは変更なし | host opaque action、menu/shortcut、root認証付き一回配送 |
| 検索強調 | grapheme境界のstrict validator | UTF-8論理一致を保持するgrapheme表示投影 |

公開DTOの既存struct literalを維持する。入力・focus・IME・popup・geometry・履歴cursor/draftはKUCが所有し、hostにはopaque target/correlationと必要な値だけを通知する。
