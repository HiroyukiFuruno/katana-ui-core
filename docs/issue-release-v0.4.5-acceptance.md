## 証跡の読み方

- 「対応済み」は、公開 root/adapter を実際に描画し、node bounds・state・typed effect 等を assertion しているものに限る。
- `forward_events_once` の成功や event 件数だけを、host state / AccessKit bounds の証拠とは扱わない。
- 「不足」は実装変更を意味せず、現行 checkout で受入条件に対応する公開 regression assertion を特定できなかったという記録である。
- この資料は受入対応表であり、全 gate・公開・release 完了を断定しない。
