## ADDED Requirements

### Requirement: CodeDiff widget

CodeDiff MUST 2つのコード文字列を受け取り、行番号付きの差分として表示できる。
CodeDiff MUST 分割表示（split）と内包表示（inline）を切り替えられる。
CodeDiff MUST 既定では分割表示（split）の左右表示で開く。

#### Scenario: 2つの入力を受け取る

- **WHEN** 利用者が変更前と変更後の `CodeDiffSource` を渡す
- **THEN** CodeDiff はそれぞれの本文、表示開始行、行数を使って差分を構築する
- **AND** 行番号は表示開始行から始まる

#### Scenario: 入力行数が本文と一致しない

- **WHEN** 渡された行数が本文から算出した表示行数と一致しない
- **THEN** CodeDiff は差分を曖昧に表示しない
- **AND** 利用側が検知できるエラーを返す

#### Scenario: 差分がない

- **WHEN** 変更前と変更後の本文が同じ
- **THEN** CodeDiff は差分なし状態を表示する
- **AND** 追加行数と削除行数はどちらも 0 として参照できる

#### Scenario: 左右の分割表示で見る

- **WHEN** 表示形式が分割表示（split）で、方向が左右表示
- **THEN** 変更前は左、変更後は右に表示される
- **AND** 対応する変更行は同じ高さにそろう
- **AND** 変更前と変更後の間には常時見える境界が表示される
- **AND** 長い行の横スクロール位置は左右で同期される

#### Scenario: 上下の分割表示で見る

- **WHEN** 表示形式が分割表示（split）で、方向が上下表示
- **THEN** 変更前は上、変更後は下に表示される
- **AND** 対応する変更行は同じ順序で読める
- **AND** 変更前と変更後の境界が見た目で分かる

#### Scenario: 内包表示で見る

- **WHEN** 表示形式が内包表示（inline）
- **THEN** 削除行と追加行は1列の中で上下に並ぶ
- **AND** 分割方向の左右表示・上下表示の指定は無効になる

#### Scenario: 変更行を読む

- **WHEN** 1行内の一部だけが変わっている
- **THEN** 行全体は薄くハイライトされる
- **AND** 実際に変わった文字範囲はより濃くハイライトされる
- **AND** 日本語など複数バイト文字を含む行でも、ハイライト範囲は表示文字単位でずれない

#### Scenario: 空行を挟む類似行を読む

- **WHEN** 削除行と追加行の間に空行だけの未変更行がある
- **THEN** CodeDiff は類似する削除行と追加行を対応付ける
- **AND** 対応行の局所ハイライトを表示する

#### Scenario: 追加行と削除行を読む

- **WHEN** 変更前だけにある行、または変更後だけにある行がある
- **THEN** 削除行と追加行は異なる色味（tone）で表示される
- **AND** 分割表示では存在しない側にプレースホルダーが表示される

#### Scenario: 空行と末尾改行の差分を読む

- **WHEN** 空行または末尾改行の有無だけが変わる
- **THEN** CodeDiff は空行を差分行として表示する
- **AND** 空行は `↵` で表示される

#### Scenario: 空白文字の差分を読む

- **WHEN** 空白（space）またはタブ（tab）の有無だけが変わる
- **THEN** 変更範囲内の空白（space）は `·` で表示される
- **AND** 変更範囲内のタブ（tab）は `→` で表示される

#### Scenario: 未変更行を省略する

- **WHEN** 変更点から離れた未変更行が連続している
- **THEN** CodeDiff は既定でそのブロックを省略表示する
- **AND** 省略行には非表示行数が表示される
- **AND** 省略行は開閉アイコン付きの横長バーとして表示される

#### Scenario: 省略された未変更行を表示する

- **WHEN** 利用者が省略行を押す
- **THEN** CodeDiff は対象の未変更ブロックを展開する
- **AND** 利用者は再度省略できる

#### Scenario: Storybook で確認する

- **WHEN** Storybook の CodeDiff ページを開く
- **THEN** 左右分割、上下分割、内包表示を操作で切り替えられる
- **AND** 追加、削除、差分なし、局所変更、空白変更、末尾改行、省略展開、長い行の横スクロールを確認できる
