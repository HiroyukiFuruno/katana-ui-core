## ユーザー要件

- [x] 2つの文字列を受け取り、コード変更差分として表示する。
- [x] 各文字列は本文、表示開始行、行数を受け取る。
- [x] 既定表示は分割表示（split）の左右表示とする。
- [x] 分割表示（split）では左右表示と上下表示を切り替えられる。
- [x] 内包表示（inline）では削除行と追加行を上下に並べ、左右・上下の切り替えを無効にする。
- [x] 変更箇所を局所ハイライトし、変更行全体も薄くハイライトする。
- [x] 削除、追加、空行、末尾改行の表現は Katana の既存差分確認仕様を参考にする。
- [x] 変更点から離れた未変更行は既定で省略し、操作で表示できる。
