# コード差分（CodeDiff）

> Archive candidate: CodeDiff の KUC 実装要件は `openspec/changes/establish-kuc-atoms-molecules-catalog/` へ移管する。この change は要件移管後に archive 候補として扱う。

## 目的

2つのコード文字列を受け取り、変更前と変更後の差分を読むための汎用画面部品（widget）を追加する。
画面上では、行番号付きのコード差分として表示され、利用者は分割表示（split）と内包表示（inline）を切り替えられる。

## 背景

Katana にはファイル修正の承認画面として差分確認 UI がある。
ただし、既存の `DiffViewer` はファイルパス、複数ファイル移動、修正の反映・拒否といった Katana 固有の責務を含む。

この change では、そのまま移植せず、差分計算と表示仕様だけを参考にする。
対象は「2つの文字列を見比べる表示専用の CodeDiff」であり、lint、ファイル保存、修正適用、複数ファイル確認は扱わない。

## 範囲

- `CodeDiff` を `composite/code_diff` に追加する
- 入力は変更前・変更後それぞれについて、本文、表示開始行、行数を受け取る
- 行単位の追加、削除、変更なしを判定する
- 変更行では、行全体を薄く強調し、実際に変わった文字範囲をより濃く強調する
- 表示形式は分割表示（split）と内包表示（inline）を切り替えられる
- 既定表示は分割表示（split）の左右表示とし、利用側から初期表示を指定できる
- 分割表示（split）は左右表示と上下表示を切り替えられる
- 内包表示（inline）は削除行と追加行を上下に並べる表示とし、左右・上下の切り替えは無効にする
- 追加行数、削除行数、差分なし状態を表示できる
- 削除、追加、空行、末尾改行の差分は Katana の既存差分確認仕様を参考にして表現する
- 変更点から離れた未変更行は既定で省略し、利用者操作で展開できる
- Storybook に操作可能な確認ページを追加する

## 範囲外

- ファイルの読み書き
- git patch の生成や適用
- 複数ファイルのページ送り、承認、拒否
- Problems パネル、lint、自動修正との連携
- コード編集機能
- 言語別の構文色分け
- Katana の egui UI の完全再現

## 既存方針との関係

既存 backlog で除外していた `DiffViewer` は、Katana 固有の差分承認画面を指す。
この change の `CodeDiff` は、2つの文字列を表示するだけの責務を混ぜない汎用部品として追加する。
